# Deutsch-Trainer для Android

Тренер у застосунку + **охоронець**, що закриває TikTok і YouTube,
доки в поточну зміну не здано **новий урок на 1** (від 92%).

## Розклад
| Зміна | Час | Що потрібно |
|---|---|---|
| Ранок | 4:00 – 18:00 | новий урок на 1 → вільні до 18:00 |
| Вечір | 18:00 – 4:00 | ще один новий урок на 1 → вільні до 4:00 |

- **Новий урок** — той, що ще не був зданий на 1. Якщо таких не лишилося,
  рахується будь-який (наповнені всі уроки A1: 1–24 і фокуси Ф1–Ф5).
- Урок, зданий на 1, коли й так було вільно, у запас не йде: увечері він уже не «новий».
- Блокується застосунок TikTok (і Lite), YouTube, а також tiktok.com / youtube.com
  у Chrome, Samsung Internet, Firefox, Edge, Opera, Brave, Яндекс і Mi Browser.

## Встановлення на телефон
1. Перекиньте `build/deutsch-trainer.apk` на телефон (кабель, Telegram «Збережене», KDE Connect).
2. Відкрийте файл → дозвольте встановлення з цього джерела → «Встановити».
3. Відкрийте Deutsch-Trainer → жовта кнопка «Увімкнути» вгорі → «Спеціальні можливості» →
   «Охоронець Deutsch-Trainer» → увімкнути.
   Якщо перемикач сірий («обмежене налаштування»): Налаштування → Застосунки →
   Deutsch-Trainer → меню ⋮ → «Дозволити обмежені налаштування», і ще раз крок 3.
4. На Xiaomi / Huawei / Samsung варто вимкнути для застосунку економію батареї,
   щоб система не вбивала охоронця.
5. Прогрес у застосунку окремий від браузера. Перенести: у браузері
   «Параметри → Зберегти копію», у застосунку «Параметри → Відновити з копії».

## Як це влаштовано
- Сайт вантажиться з GitHub Pages у WebView, тож нові уроки з’являються після
  `git push` без перевстановлення. Зміни коду застосунку — нова збірка APK.
- `GuardService` — служба спеціальних можливостей. Отримує події лише від застосунків зі
  списку в `res/xml/guard_service.xml` (має збігатися з `Schedule.java`).
- `Schedule` — зміни, стан «закрито / вільно», відповідь сайту.
- `MainActivity` — смуга стану вгорі + WebView, озвучка голосом телефона, копія прогресу.
- **Міст сайт ↔ застосунок** — `window.DTApp` (є лише в застосунку):
  - `lessonPassed(id, pct, isNew)` → JSON `{counted, title, text}` — викликає `js/views/exercises.js`;
  - `speak(text, rate, pitch, id)` / `stopSpeaking()` — кінець фрази приходить у
    `window.__dtSpoken(id)` (`js/speech.js`);
  - `saveBackup(name, json)` — «Зберегти копію» (`js/views/settings.js`).

  Не перейменовуйте ці функції без оновлення застосунку.

## Збірка
```
./android/build.sh                                  # для телефона
SITE_URL=http://10.0.2.2:8000/ ./android/build.sh   # для емулятора з локальним сервером
```
- Перед новою версією збільште `VERSION_CODE` у `build.sh`.
- **Ключ підпису — `~/Android/keys/`, поза репозиторієм. Не губіть і не комітьте:**
  без нього телефон не дасть оновити застосунок (лише видалити разом із прогресом).
- JDK — `~/.local/opt/jdk-17*`, SDK — `~/Android/Sdk`, емулятор — AVD `dt-test`.
