# Deutsch-Trainer — сайт для вивчення німецької

## Мета
Особистий сайт для вивчення німецької з нуля до рівня **B1+** за ~1,5 року
(30–60 хв на день). Працює на ПК і телефоні, прогрес синхронізується автоматично.
Користувач один (автор проєкту). Мова інтерфейсу — українська.

## Про автора
- Програмує трохи: пояснюй рішення простими словами, коротко коментуй код.
- Працює на Windows і Kubuntu.
- Відповідай українською.

## Статус (оновлюй після кожного етапу)
- ✅ Етап 1: каркас, список уроків A1, картки з інтервальним повторенням (SM-2).
- ✅ Етап 2: вправи (вибір варіанта, пропуск, порядок слів, переклад, розминка з артиклями) + озвучка.
- ✅ Етап 3: стрес-тест голосом із запасним режимом клавіатури.
- ✅ Етап 6 (базово): стрік, рекорд стрес-тесту, карта прогресу A1 → B1+, рядок тижня.
- ✅ Цікавіші уроки: сцена-діалог з озвучкою і «Цікаво знати» в уроках 1–6;
  у вправах «знайди пари», диктант на слух, німецька шкільна оцінка 1–6 і список помилок.
- ⏳ Етап 4: Firebase — ще не почато. Поки є ручна резервна копія (Параметри → «Зберегти копію»).
- ⏳ Етап 5: діалоги з ШІ через Gemini API — ще не почато.
- ⏳ Контент: A1 уроки 1–6 наповнені (173 слова), уроки 7–24 — лише план (`"planned": true`).
- ⏳ Етап 7: A2, B1, B1+.

Наступний крок: наповнити уроки A1 7–12 за тими самими правилами, потім етап 4.

## Як запустити
У папці проєкту:
```
python3 -m http.server 8000
```
і відкрити http://localhost:8000 у Google Chrome. Подвійним кліком по index.html
сайт не запрацює (браузер блокує модулі й JSON з файлів).
Розпізнавання мови працює в Google Chrome (ПК, Android); у Firefox і Chromium — ні,
тоді стрес-тест автоматично переходить на клавіатуру.
Мікрофон на телефоні працює тільки через https (тобто після публікації на хостингу).

## Навчальна програма
- Основа — структура підручника **Menschen A1 → A2 → B1**
  (теми й послідовність граматики), далі **Aspekte neu** для B1+.
- План A1 у `data/a1.json` складено **приблизно** за послідовністю Menschen A1.
  Якщо автор покаже зміст свого підручника — звір і підправ порядок тем.
- **Тексти, вправи та діалоги з підручників НЕ копіювати** (авторське право).
  Брати лише структуру тем і граматики, весь контент писати оригінальний.
  Назви уроків теж власні.
- **Лексика — тільки з перевірених списків**: офіційні Wortlisten
  Goethe-Institut A1, A2, B1 + частотні слова. Не вигадувати випадкові
  рідкісні слова (антиприклад: «паром» на рівні A1). Виняток — кілька слів,
  потрібних саме автору (die Ukraine, Ukrainisch).
  Слова уроків 1–6 підібрано за списком Goethe A1 без звірки з PDF —
  при нагоді звір зі «Start Deutsch 1 Wortliste».
- Кожне слово прив’язане до рівня і теми уроку. Іменники завжди з артиклем
  і формою множини.
- На урок: 25–30 слів, 3–4 блоки граматики, ~10 вправ, 4–7 фраз для стрес-тесту.
  Приклади речень — тільки з уже знайомою граматикою, коротко й природно.
- **Сцена** (`scene`): живий діалог на 8–10 реплік, з якого починається урок.
  Тільки слова й граматика цього та попередніх уроків (імена й міста можна).
  Наскрізні персонажі: Olena (українка в Берліні), Max (її друг-вчитель),
  Frau Weber (викладачка), Herr Braun (начальник Олени). Можна додавати нових.
- **Цікаво знати** (`fact`): 1–2 речення про реальне життя в Німеччині, Австрії чи Швейцарії,
  пов’язані з темою уроку. Лише перевірені факти.

## Функції
1. **Картки з інтервальним повторенням** (SM-2, `js/srs.js`):
   слово ↔ переклад, множина, форми дієслова, приклад речення, озвучка.
   Нові слова спершу показуються німецькою. Денний ліміт нових — у параметрах.
2. **Вправи на граматику** (`js/views/exercises.js`): складання речень, артиклі,
   пропуски, переклад. Автоматично зі слів уроку додаються: 4 питання на артиклі,
   «знайди пари» (5 слів) і 2 диктанти на слух (з прикладів `ex` до 6 слів).
   У кінці — оцінка як у німецькій школі (1 найкраща, 6 найгірша) і список помилок.
3. **Аудіо та вимова**: озвучка через `speechSynthesis` (de-DE), вибір голосу і швидкості.
4. **Діалоги з ШІ** через **Gemini API** (етап 5): рольові сценарії за темою уроку,
   ШІ виправляє помилки й пояснює їх українською.
   - Ключ API користувач вводить у **параметрах сайту**, ключ зберігається
     лише в браузері (localStorage) **окремим ключем**, не в об’єкті прогресу —
     щоб він не потрапив у резервну копію і в Firebase.
   - **Ніколи не вписувати ключ у код і не комітити його в репозиторій.**
   - Назву моделі зробити налаштовуваною (моделі Gemini часто перейменовують).
5. **Стрес-тест** (головна фішка, `js/views/stress.js`):
   - На слово 10 секунд (налаштовується), на речення +5. Відповідь **голосом**
     (Web Speech API, `lang = "de-DE"`), або з клавіатури.
   - Типи питань: переклад слів UA→DE, слово з артиклем (der/die/das),
     переклад коротких речень, відповідь на питання (напр. «Wie alt bist du?»).
   - Підказка: **перші літери** (для артиклів — правило або складне слово),
     коштує половину балів.
   - Порівняння нечутливе до регістру, розділових знаків, умлаутів (ä = ae),
     цифр (21 = einundzwanzig) і дрібних помилок розпізнавання (`js/match.js`).
   - Якщо розпізнало неправильно — кнопка «Зарахувати» (50 балів).
   - Питання лише з уже вивченого (картки, які хоч раз відповідали).
   - Слова з помилками потрапляють у сьогоднішнє повторення.
6. **Мотивація**: стрік днів, рекорд стрес-тесту, карта прогресу A1 → B1+
   (кожна клітинка — урок, зафарбовується за прогресом).

## Технічне
- Сайт на **чистому JavaScript (ES-модулі) без збірки й без npm** — щоб усе було
  зрозуміло й працювало просто з папки. Не додавати фреймворки без потреби.
- Адаптивний дизайн: телефон у першу чергу, ПК теж. Світла й темна тема
  (`prefers-color-scheme`).
- Синхронізація прогресу (етап 4): **Firebase** (Authentication + Firestore,
  безкоштовний план), вхід через Google. Firebase підключати з CDN
  (`https://www.gstatic.com/firebasejs/...`), без npm.
  Весь прогрес — один об’єкт у `js/storage.js` (`getState()` / `save()`),
  синхронізацію додавати саме там.
- Хостинг: Firebase Hosting або GitHub Pages (адреси на `#/…`, тож налаштування
  маршрутів не потрібні).
- Контент (слова, уроки, вправи) — у JSON-файлах `data/`, окремо від коду.

## Структура файлів
```
index.html            — каркас сторінки, шапка, вкладки
css/style.css         — увесь дизайн (токени кольорів на :root)
js/app.js             — запуск і маршрути (#/, #/lessons, #/lesson/:id, #/cards, #/cards/:id,
                        #/exercises/:id, #/stress, #/settings)
js/storage.js         — прогрес і параметри в localStorage (ключ 'deutsch-trainer/v1'), стрік
js/srs.js             — алгоритм повторення
js/content.js         — завантаження data/*.json
js/match.js           — перевірка відповідей (чисті функції)
js/speech.js          — озвучка, розпізнавання мови, звуки
js/ui.js              — дрібні помічники (іконки, екранування, кнопки)
js/views/*.js         — сторінки; кожна повертає функцію прибирання (таймери, мікрофон)
data/levels.json      — рівні A1…B1+
data/a1.json          — уроки A1
tools/check_content.py — перевірка контенту
```

## Формат контенту (data/a1.json)
```jsonc
{
  "id": "a1-03", "num": 3, "title": "Моя сім’я", "titleDe": "Meine Familie",
  "topic": "…",
  "scene": { "title": "Моя родина", "lines": [
    { "who": "Max", "de": "Wer ist das?", "ua": "Хто це?" } ] },   // різні персонажі звучать різною висотою голосу
  "fact": "текст з **жирним**",
  "grammar": [{ "title": "…", "text": "текст з **жирним**\nі новими рядками",
                "table": [["", "колонка"], ["рядок", "значення"]] }],  // перший рядок з "" — заголовок
  "words": [
    { "id": "a1-mutter", "de": "Mutter", "art": "die", "pl": "Mütter", "pos": "n",
      "ua": "мати, мама", "ex": "Meine Mutter heißt Olga.", "exUa": "Мою маму звати Ольга." },
    { "id": "a1-eltern", "de": "Eltern", "art": "die", "plOnly": true, "pos": "n", "ua": "батьки" },
    { "id": "a1-sprechen", "de": "sprechen", "pos": "v", "forms": "du sprichst, er spricht", "ua": "…" },
    { "id": "a1-mein", "de": "mein", "alt": ["meine"], "pos": "pron", "note": "…", "ua": "мій, моя" }
  ],
  "exercises": [
    { "type": "choice", "q": "Das ist ___ Mutter.", "options": ["meine", "mein"], "answer": "meine", "explain": "…" },
    { "type": "gap", "q": "Er ___ Deutsch.", "hint": "sprechen", "answers": ["spricht"], "explain": "…" },
    { "type": "order", "words": ["du", "Sprichst", "Deutsch"], "answers": ["Sprichst du Deutsch?"], "ua": "…" },
    { "type": "translate", "ua": "…", "answers": ["…", "інший правильний варіант"] }
  ],
  "speak": [
    { "type": "sentence", "ua": "Я вчу німецьку.", "answers": ["Ich lerne Deutsch."] },
    { "type": "question", "de": "Wie alt bist du?", "ua": "…",
      "accept": ["ich bin # jahre alt", "#"], "example": "Ich bin 20 Jahre alt." }
  ]
}
```
- `pos`: n, v, adj, adv, pron, prep, conj, num, phr, name (назви без артикля).
- `id` слова **ніколи не змінювати** — до нього прив’язаний прогрес. Нові слова — нові id.
- `pl: null` — іменник без множини (die Ukraine). `alt` — інші прийнятні відповіді.
- `say` у вправі — що озвучити, якщо в `q` немає `___`.
- У `accept`: `*` — будь-який текст, `#` — число.
- Запланований урок: `"planned": true` і `"grammarPlan": [...]` без слів.

## Правила для коду
- Після змін у `data/` обов’язково запускай `python3 tools/check_content.py` — помилок має бути 0.
- Не ламай формат прогресу в `js/storage.js`: старі дані мають завантажуватися
  (нові поля додавай через значення за замовчуванням у `withDefaults`).
- Тексти інтерфейсу — українською, коротко і по ділу; кнопка каже, що станеться.
- Дизайн: зошит у клітинку, картки як Karteikarte, головна кнопка — жовтий
  текстовиділювач, кольори роду der синій / das зелений / die червоний.
  Нові екрани роби в тому ж стилі, кольори бери з токенів у `css/style.css`.
- Перевіряй зміни в браузері: телефон (≈390 px) і ПК, світла й темна тема.
