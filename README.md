# Deutsch-Trainer

Особистий тренажер німецької: від нуля до B1+.
Сайт: **https://backerydot.github.io/Claude/** · гра: **https://backerydot.github.io/Claude/game.html**
Картки з інтервальним повторенням, вправи на граматику, озвучка
і стрес-тест, де відповідаєш уголос на час.

## Запуск

1. Відкрий термінал у цій папці.
2. Запусти локальний сервер:
   ```
   python3 -m http.server 8000
   ```
3. Відкрий у браузері **http://localhost:8000**.

Найкраще працює в **Google Chrome**: тільки він уміє розпізнавати мову для стрес-тесту.
У Firefox і Chromium стрес-тест працює з клавіатури.

## Як вчитися щодня (30–60 хвилин)

1. **Картки** — повтори все, що на сьогодні, і вивчи нові слова (за замовчуванням 10 на день).
2. **Урок** — прочитай граматику і зроби вправи до поточного уроку.
3. **Стрес-тест** — 15 питань на швидкість, щоб слова виходили з голови самі.

## Розробка з Claude Code

```
claude
```
і напиши, наприклад: «Прочитай CLAUDE.md і наповни уроки 7–8» або «Почни етап 4».
Усі правила проєкту — у файлі `CLAUDE.md`.

Після змін у словах чи вправах перевір контент:
```
python3 tools/check_content.py
```

## Прогрес

Прогрес зберігається в браузері. Щоб не втратити його, у **Параметрах**
натисни «Зберегти копію». Синхронізація між пристроями — наступний етап.
